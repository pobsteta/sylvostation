# Grandes formes d'humus admises dans le gabarit de station

Grandes formes seulement (Mull, Moder, Mor, Amphi, Tangel), **à
vérifier** : le Référentiel humus de l'AFES et Jabiol et al. n'ont pas
été lus. Aucune sous-forme n'est proposée.

## Usage

``` r
HUMUS_FORMS
```

## Format

Un vecteur de caractères.
