# Variables fines (interdites aux placettes IFN)

Variables dont la résolution est bien plus fine que la précision de
localisation des placettes de l'IFN (700 m). La correspondance est
insensible à la casse. Les noms commençant par `lidar_`, `mnt_`, `mhc_`
ou `k_` (facteur de rayonnement, mission 021) sont aussi considérés
comme fins.

## Usage

``` r
FINE_VARIABLES
```

## Format

Un vecteur de caractères.
