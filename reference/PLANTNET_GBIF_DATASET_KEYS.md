# Jeux GBIF Pl@ntNet (identification par algorithme)

`datasetKey` des deux jeux Pl@ntNet vus dans l'emprise
(`docs/referentiels.md`, § 8 et § 33.1) : « Pl@ntNet automatically
identified occurrences » et « Pl@ntNet observations ». Une photo = une
espèce, identification non validée :
[`clean_occ()`](https://pobsteta.github.io/sylvostation/reference/clean_occ.md)
les écarte par défaut. Liste **non exhaustive** : d'autres jeux Pl@ntNet
peuvent exister ailleurs (à vérifier hors emprise).

## Usage

``` r
PLANTNET_GBIF_DATASET_KEYS
```

## Format

Un vecteur de caractères.
