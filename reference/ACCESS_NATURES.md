# Natures de tronçons BD TOPO retenues comme accès

Valeurs du champ `nature` de `BDTOPO_V3:troncon_de_route` lues au WFS
sur l'emprise test le 2026-11-18 (docs/referentiels.md, § 29) : routes
(à une ou deux chaussées, bretelles, ronds-points), routes empierrées et
chemins. Les sentiers et escaliers sont exclus.

## Usage

``` r
ACCESS_NATURES
```

## Format

Un vecteur de caractères.
